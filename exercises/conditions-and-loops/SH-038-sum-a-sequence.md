# SH-038 — Sum a Sequence

**Description**

Accept a positive integer N and print the sum of integers from 1 through N.

**Requirements**

Use a loop with an accumulator; learn variable updates and Bash integer arithmetic.

**Tips**

An accumulator starts with a known value and is updated each iteration. For a sequence sum, identify the inclusive range, add each term, and print the final accumulator after the loop. Bash arithmetic is integer-based. Test a small sequence whose total you can calculate manually.


**How to approach it:** Identify the required input, the expected output, and the command or Bash feature that connects them. Try a small controlled example first, then check the result against the example and the description. Keep paths and expanded variables quoted where appropriate; do not assume example paths or timestamps are fixed.

**Example**

```text
5 → 15
```
